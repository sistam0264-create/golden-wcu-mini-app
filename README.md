# Golden WCU Freshman Tutorial — Full Menu App

This package replaces the small starter menu with a fuller, data-driven Golden WCU Freshman Tutorial Mini App.

## Included
- Freshman 1st and 2nd semester course menus
- General Physics PHYS 1011 Chapters 1–7 menu
- Learn → Practice → Test architecture
- Golden Tip / strategic study guidance
- Chapter 1 interactive quiz starter
- Fluid Mechanics critical-practice quiz starter
- Materials library
- Wachemo University vs Different Universities exam separation
- University collection index
- Updates and Support pages
- Telegram WebApp integration
- Mobile-first design

## Materials included in this package
- General Physics Phys 1011 Module.pdf
- Chapter 5 — Oscillations, Waves and Optics.pptx
- Physics Worksheet Collection.pdf
- Wachemo Physics Final Exam.pdf
- Individual other-university physics exams that were collected in this project
- Selected exam collection bundles

Duplicate copies of the same WSU/WkU files were not intentionally copied twice.

## IMPORTANT: GitHub Pages and premium content
GitHub Pages is public. Do NOT put protected/paid PDFs on GitHub Pages if they must remain private.
For true premium access, use a backend that validates Telegram `initData` on the server and returns protected content only to entitled users.

For a first static demo, the included resource links work after the `materials/` folder is uploaded together with the app. If the repository is public, those linked files are public too.

## Deploy/update
1. Replace the old `index.html`, `style.css`, `app.js` in the GitHub repo with these versions.
2. Add `data.js`.
3. Add the `materials/` folder and its files if you intentionally want them public.
4. Keep GitHub Pages on `main` / root.
5. The same existing Main Mini App URL can continue to be used; no BotFather URL change is needed just because the files changed.
6. Future content can be added by editing `data.js` and adding files/links; the bot itself does not need to be recreated.
